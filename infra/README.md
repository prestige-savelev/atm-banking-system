Команды для PostgreSQL:

- `docker compose -f ./infra/postgres.yml up -d`
- `docker compose -f ./infra/postgres.yml down`
- `docker compose -f ./infra/postgres.yml down -v`

Команды для MongoDB:

- `docker compose -f ./infra/mongo.yml up -d`
- `docker compose -f ./infra/mongo.yml down`
- `docker compose -f ./infra/mongo.yml down -v`
